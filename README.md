# 🍳 냉장고 파먹기

앱인토스(App in Toss) **비게임** 미니앱 『냉장고 파먹기』 프로토타입입니다.
냉장고 문을 열어 **있는 재료를 톡톡 고르면**, 오늘 만들 수 있는 요리를 매칭률 순으로 알려 줘요.

- **냉장고 내부 UI**: 라이트 블루/화이트 냉장고 본체(문 손잡이·도어 라인·3°C 표시) 안에
  냉장실 선반 3칸 + 문쪽 포켓 — **신선칸(채소·버섯) · 고기칸(고기·해산물) · 달걀칸(두부·유제품) · 문쪽 포켓(양념·밥·면)** —
  에 재료 36종을 아이콘 + 이름으로 배치했어요. 냉장실 세 칸은 앞면 라벨 판을 칸별 색(초록·붉은기·노랑)으로,
  문쪽 포켓은 한 단 낮은 회청색 포켓으로 따로 보이게 나눴습니다. 재료를 누르면 반짝 올라오며 냉장고에서 꺼내는 느낌이 나요.
- **🍽 원터치 빠른 조합**: 검색창 아래 `🍚 김치+밥+대파` · `🥔 감자+당근+양파` · `🍞 식빵+계란+치즈` 칩을
  **한 번만 누르면** 재료가 냉장고에서 자동으로 담기고 결과 목록으로 이동해요. 세 조합 모두 `바로 가능` 요리가 1개 이상 나와요.
- **재료 고르는 방법 안내**: 냉장고 안쪽에 `1탭 → ✓ 꺼냄` / `2탭 → 🔥 임박` / `3탭이면 다시 해제` 칩을 상시 노출해
  처음 들어온 사람도 누르기 전에 동작을 알 수 있어요.
- **🔥 임박 재료**: 꺼낸 재료를 **한 번 더 누르면** 주황색 임박 표시가 되고, 그 재료를 쓰는 요리가
  결과 맨 위 `🔥 임박 재료 소진 추천`으로 올라와요.
- **🛒 장보기 메모**: 부족한 재료 배지(`+ 참치캔`)를 누르면 장보기 메모에 모이고,
  그 순간 하단 🛒 버튼이 **튀어오르며 파란 링·배지 카운트가 강조**돼요. 메모 시트에서 하나씩 체크하거나 **텍스트로 복사**할 수 있어요.
- **1인분 ↔ 2인분 계량 전환 + 원터치 타이머**: 상세 레시피에서 분량 버튼을 누르면 계량이 즉시 절반/2배가 되고,
  조리 단계 옆 `⏱ 4분` 칩을 누르면 바로 카운트다운 타이머가 돌아가요(일시정지·재시작·알림음).
- **광고 사전 안내 → 보상형 광고 → 상세 레시피**: 카드의 `▶ 레시피 보기 [광고]`를 누르면 먼저 "짧은 광고를 보고 레시피를 열까요?"
  안내 모달이 뜨고, `광고 보고 열기`를 누르면 보상형 광고 SDK 브릿지(없으면 3초 데모 광고)가 실행된 뒤
  1·2인분 계량, 단계별 조리법, 실패 방지 팁이 열려요. 한 번 연 레시피는 세션 동안 `다시 보기`로 바로 열려요.
- 순수 정적 웹앱 (`iframe`, `eval`, SSR, 외부 라이브러리 없음)
- 외부 폰트·이미지·CDN 요청 0건 — 요리 그림과 재료 아이콘은 **직접 그린 인라인 SVG**

## 2. 화면과 흐름

휴대폰 세로 화면(390×844)에서 **원터치 조합 + 냉장고 + 선택 현황까지 한 화면**에 들어오도록 여백을 잡았어요.
(실측: 콤보 줄 170~233px, 냉장고 241~735px(494px), 툴바 하단 774px < 하단 바 상단 779px)

1. **상단 바** — 뒤로가기 · 냉장고 아이콘 · `냉장고 파먹기` · 공유
2. **인트로** — "우리 냉장고, 열어 볼까요?"
3. **재료 검색** — 이름으로 찾기(예: 두부). 검색하면 해당 재료가 있는 선반만 남아요.
4. **원터치 빠른 조합** — `🍚 김치+밥+대파` · `🥔 감자+당근+양파` · `🍞 식빵+계란+치즈`.
   한 번 누르면 세 재료가 담기고 결과로 스크롤되며, 담긴 조합 칩은 초록 `✓`로 바뀌어요.
5. **냉장고**
   - 문 손잡이·도어 라인·`냉장실 3°C` 표시가 있는 라이트 블루/화이트 본체
   - 패널 아래 `1탭 → ✓ 꺼냄` · `2탭 → 🔥 임박` · `3탭이면 다시 해제` 안내 칩 상시 표시
   - 냉장실 세 칸(신선·고기·달걀)은 아이콘 + 이름 타일 5열, 앞면 라벨 판은 칸별 색(초록·붉은기·노랑)과
     왼쪽 색 막대, 유리 선반 라인으로 구분. 라벨 판에 `N개 꺼냄` 표시
   - **문쪽 포켓**(양념·밥·면)은 한 단 낮은 회청색 포켓 안에 **6열 2줄**로 따로 담겨 냉장실과 확실히 구분돼요
   - **탭 1번 = 꺼내기**(초록 하이라이트 + 체크) → **한 번 더 = 🔥 임박**(주황 하이라이트 + 불꽃) → 한 번 더 = 원래대로
6. **선택 현황** — `선택한 재료 N개 · 🔥 M`, `자주 쓰는 재료 담기`, `전체 비우기`
7. **결과** — 카드 왼쪽 색선과 배지로 `✓ 바로 가능`(초록) / `+1개만 더`(주황 테두리) / `+2개 필요`(회색)를 구분,
   보유 재료(초록)·부족 재료(회색 `+`)·임박 재료(🔥) 칩, 매칭률 막대, 조리 시간·난이도.
   카드 버튼은 `▶ 레시피 보기` + 작은 `광고` 표시, 이미 연 레시피는 `✓ 다시 보기`. `🔥 임박 재료 소진 추천`이 있으면 맨 위에 먼저 나와요.
8. **하단 고정 바** — `N개 골랐어요` + `요리 보기`(결과로 스크롤)
9. **장보기 메모** — 담은 게 있으면 하단에 🛒 버튼이 떠요. 담는 순간 버튼이 튀어오르고 링·카운트가 강조돼요. 시트에서 체크·삭제·전체 복사.
10. **상세 레시피** — 광고를 본 뒤에만 열립니다. 인분 전환, 단계별 타이머, 팁.

### 매칭 규칙

- 보유 재료 수 / 필요 재료 수 = 매칭률. **부족 0개 = `바로 가능`**, 1~2개 = `1개만 더` / `2개만 더`.
- 기본은 부족 2개까지 보여 주고, 결과가 3개 미만이면 부족 3개짜리까지 보여 주며 안내 문구를 붙여요.
- 정렬: 부족 개수 ↑ → 매칭률 ↓ → 조리 시간 ↑.
- 임박 재료가 걸린 요리는 별도 섹션으로 올리고, 그 안에서는 임박 재료를 많이 쓰는 순서로 정렬해요.

## 4. 설정과 브리지

`app.js` 맨 위 `CONFIG` 한 곳에서 조정합니다.

```js
var CONFIG = {
  appName: '냉장고 파먹기',
  appUrl: 'https://bubble-collab.github.io/fridge-recipe/',

  // ★ 앱마다 새로 발급받은 보상형 광고 그룹 ID
  rewardedAdGroupId: 'ait-ad-test-rewarded-id',

  demoAdSeconds: 3,     // 프로토타입 데모 광고 길이(초)
  maxMissing: 2,        // 부족 2개까지 노출
  baseServings: 2,      // 계량 기준 인분
  quickPick: ['rice', 'kimchi', 'pa', 'egg', 'onion'],

  // 첫 화면 1탭 조합 (조합마다 '바로 가능' 요리가 1개 이상 나오게 골랐어요)
  combos: [
    { id: 'c-kimchi', emoji: '🍚', label: '김치+밥+대파', items: ['kimchi', 'rice', 'pa'] },
    { id: 'c-potato', emoji: '🥔', label: '감자+당근+양파', items: ['potato', 'carrot', 'onion'] },
    { id: 'c-toast', emoji: '🍞', label: '식빵+계란+치즈', items: ['bread', 'egg', 'cheese'] }
  ]
};
```

### 보상형 광고

```js
import { loadFullScreenAd, showFullScreenAd } from '@apps-in-toss/web-framework';

window.FridgeAdBridge.register({
  show(kind, adGroupId) {
    return new Promise((resolve, reject) => {
      loadFullScreenAd({
        options: { adGroupId },
        onEvent: (e) => {
          if (e.type !== 'loaded') return;
          showFullScreenAd({
            options: { adGroupId },
            onEvent: (ev) => {
              // ✅ 보상은 userEarnedReward에서만
              if (ev.type === 'userEarnedReward') resolve({ rewarded: true });
              if (ev.type === 'dismissed' || ev.type === 'failedToShow') resolve({ rewarded: false });
            },
            onError: reject
          });
        },
        onError: reject
      });
    });
  }
});
```

- 브릿지가 없거나 `show()`가 없으면 **3초 데모 광고**로 동작해요(웹 미리보기·검수 시연용).
- ⚠️ 다른 앱에서 쓰던 광고 그룹 ID를 재사용하면 정적 분석에서 반려됩니다. 앱마다 새로 발급하세요.

### 공유 · 햅틱 · 종료

```js
window.FridgeShare = { share(payload) { /* 토스 share API */ } };
window.FridgeHaptic = { trigger(type) { /* Device.triggerHaptic({ type }) */ } };
window.FridgeHost = { exit: () => Screen.close() };
```

- 공유 브릿지가 없으면 `navigator.share` → 클립보드 복사 순서로 넘어가요.
- 햅틱 브릿지가 없으면 `navigator.vibrate`, 그것도 없으면 조용히 넘어갑니다(에러 없음).
- 안드로이드 뒤로가기: `history.pushState` 가드 + `popstate`로 **종료 확인 모달**(`계속 보기` / `나가기`)을 띄우고,
  시트·모달·상세가 열려 있으면 그것부터 닫아요. 광고 재생 중에는 뒤로가기로 닫히지 않습니다.

## 6. 검증 결과 (헤드리스 Chromium · 390×844)

## 7. 배포 (GitHub Pages)

이 폴더는 그대로 GitHub Pages에 올릴 수 있는 정적 사이트예요(`index.html`이 루트).

```bash
# 1) 원격 저장소 생성 + main 푸시 (아직 저장소가 없을 때)
gh repo create bubble-collab/fridge-recipe --public --source=. --remote=origin --push

# 2) 이미 저장소가 있다면
git push -u origin main

# 3) gh-pages 브랜치 배포 (main과 같은 내용)
git push origin main:gh-pages

# 4) Pages 활성화 (gh-pages 브랜치)
gh api -X POST repos/bubble-collab/fridge-recipe/pages \
  -f 'source[branch]=gh-pages' -f 'source[path]=/'
```

배포 주소: <https://bubble-collab.github.io/fridge-recipe/>
— 앱인토스 콘솔의 웹뷰 URL에도 같은 주소를 넣어 주세요.

## 8. 알려진 한계

- 광고는 **데모**입니다. 실제 노출·수익은 `rewardedAdGroupId`와 SDK 연결 후 발생합니다.
- 공유·햅틱·알림은 브릿지 자리만 있고, 실제 동작은 토스 앱(QR 테스트)에서 확인해야 합니다.
- 레시피 계량·조리법은 프로토타입용으로 직접 작성한 안내입니다(영양·알레르기 정보 없음).
- 재료 36종·레시피 25종은 코드 안 데이터라, 추가하려면 `app.js`의 `INGREDIENTS`·`RECIPES` 배열에 넣으면 됩니다.
- iOS 사파리는 `navigator.vibrate`가 없어 토스 햅틱 브릿지가 없으면 진동이 울리지 않습니다.
- 한 번 연 레시피는 **현재 세션에서만** 잠금 해제됩니다(저장하지 않음).
